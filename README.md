**Cat Identifier (ML Side Project)**

This was an early exploratory project where I experimented with building a simple image classification model to identify cats using Google Colab.

The goal of the project was to better understand:

	•	How machine learning models are trained on image data
  
	•	Basic classification workflows
  
	•	The practical challenges of working with datasets and model outputs

What I Did

	•	Set up and trained a basic image classification model in Google Colab
  
	•	Used sample datasets to experiment with identifying cat images
  
	•	Explored model behaviour and accuracy through iterative testing
  

Why?

As a UX/Experience Designer working increasingly with AI systems, I wanted to develop a more hands-on understanding of how machine learning models work.
I specifically wanted to experiment with Google Colab.

Status

This was a short exploratory project and is not actively maintained, but it reflects my early interest in AI and ML systems, which has since evolved into designing AI-powered user experiences.
